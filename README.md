# 🚀 Социальная сеть на Django

Простой проект социальной сети, разработанный на Django.  
Пользователи могут регистрироваться, создавать посты, лайкать, комментировать и подписываться друг на друга.

---

## ✨ Возможности проекта

- 👤 Регистрация и авторизация пользователей
- 📝 Создание постов с изображениями и текстом
- ❤️ Лайки / дизлайки постов
- 💬 Комментарии
- 👥 Подписка / отписка на пользователей
- 🔍 Поиск пользователей
- 📱 Профиль пользователя
- 📰 Лента постов (только от подписок)

---

- Django

- Bootstrap 5
